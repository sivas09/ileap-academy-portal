# iLEAP Academy Portal Teacher Guide

Portal: `https://english.ileapacademy.com/`

This guide is for teachers who manage class materials, assignments, student submissions, AI feedback, and manual feedback for assigned iLEAP Academy writing levels.

## Teacher Access

Teachers can work only with levels assigned by an admin. If a level is missing, ask an admin to update your teacher account.

Typical teacher tools:

- `Dashboard`
- `Resources`
- `Assignments`
- `AI Tutor`
- `Shop`
- `Review`
- `Admin`
- `Account`

Some admin-only settings, such as user management and AI prompt management, are not available to teachers.

## Sign In

1. Open `https://english.ileapacademy.com/`.
2. Enter your teacher email and password.
3. Confirm your dashboard shows the correct assigned level or levels.

If your password does not work, use `Forgot password?` or ask an admin to reset it.

## Teacher Dashboard

Use the dashboard to quickly see:

- Assigned levels
- Recent assignments
- Recent submissions
- Available resources

The dashboard is a starting point. Use the sidebar to manage actual teaching work.

## View Resources

Open `Resources`.

Resources may include:

- Lesson PDFs
- Worksheets
- Books
- Writing examples
- Video links

Teachers can open or download resources that belong to their assigned levels.

## Add Or Edit Resources

Open `Admin`, then use `Add Resource`.

1. Choose file upload or URL.
2. Enter a title and description.
3. Choose type, access mode, level, topic, and lesson.
4. Upload the file or paste the link.
5. Click `Add resource`.

Use clear names such as `Grade 7 Week 3 Persuasive Essay Worksheet`.

Teachers should not publish unfinished materials. If unsure, save as hidden and ask an admin to review.

## Create Assignments

Open `Assignments` or `Admin`.

1. Enter a short assignment title.
2. Add complete student instructions.
3. Add word count guidance if useful.
4. Choose due date if needed.
5. Choose level, topic, and lesson.
6. Publish when ready.

Teachers can create assignments only for assigned levels.

## Edit Assignments

Open `Assignments`.

1. Find the assignment.
2. Click `Edit assignment`.
3. Update title, instructions, date, level, topic, lesson, publish status, or archive status.
4. Click `Save assignment`.

Archive assignments that should no longer be active but already have submissions. Delete only empty assignments.

## Review Student Submissions

Open `Review`.

1. Choose a level filter if needed.
2. Select a submission from the list.
3. Read the student's pasted writing.
4. Review any existing AI feedback.
5. Add manual teacher feedback.
6. Click `Save feedback`.

Manual teacher feedback is visible to the student.

## Use AI Tutor

Open `AI Tutor`.

1. Select the student.
2. Select the assignment or choose general writing practice.
3. Paste the student's writing.
4. Click `Get feedback`.
5. Review the AI feedback.

AI Tutor feedback may include:

- Mark out of 10
- Content
- Grammar and punctuation
- Academic vocabulary
- Structure
- Transition words
- Overall advice

Review AI feedback before relying on it. Add manual feedback when the AI misses class-specific instruction or needs correction.

## Good Feedback Practice

Useful teacher feedback should:

- Name one or two strengths.
- Explain the highest-priority correction.
- Give one clear next step.
- Use language appropriate for the student's grade level.
- Avoid overwhelming the student with too many corrections at once.

Example:

```text
Your topic sentence is clear, and your example supports the main idea. Next, fix sentence boundaries: sentence 3 is a run-on sentence. Break it into two shorter sentences so the reader can follow your point.
```

## Student Submission Notifications

When a student submits homework, the portal can notify the office or assigned teacher if email is configured. If notifications are missing, continue checking `Review` and ask an admin to verify SMTP settings in Render.

## Teacher Weekly Workflow

1. Confirm the week's topic and lesson are published.
2. Confirm resources are visible.
3. Publish the assignment.
4. Monitor submissions in `Review`.
5. Run AI Tutor where useful.
6. Add manual feedback.
7. Ask students to read feedback and revise.

## Account Settings

Open `Account` to change your password.

Use a password that is not shared with students or parents.
