# iLEAP Academy English Writing Portal - User Role Guide

Date: May 20, 2026  
Portal URL: `https://english.ileapacademy.com/`  
Scope: English Writing Program portal

## 1. Purpose

This guide explains what students, teachers, and admins can do inside the iLEAP Academy English Writing Portal. It is written as an operating guide for the current portal, not as a technical document.

The portal supports three English Writing Program levels:

- Grade 2/3
- Grade 4/5/6
- Grade 7/8/9

Each user sees portal tools based on their role and access level.

## 2. Student Guide

Students use the portal to access their writing level, view assignments and resources, submit writing work, and read feedback.

### Student Login

Students should:

1. Go to `https://english.ileapacademy.com/`.
2. Log in with the email and password provided by iLEAP Academy.
3. Confirm that their dashboard shows the correct writing level.

If a student is in the wrong level, an admin must update the student's level.

### Student Dashboard

The dashboard gives the student a simple overview of their portal account. Students should be able to see:

- their name
- their assigned writing level
- recent assignments
- available resources
- recent feedback when available

### Resources

Students can open the `Resources` section to see learning materials for their assigned level.

Resources may include:

- notes
- PDF documents
- worksheets
- YouTube video links
- writing examples
- class handouts

Students should only see resources that are assigned to their level or made available to all students.

### Assignments

Students can open the `Assignments` section to see homework or writing tasks assigned to their level.

Each assignment may include:

- assignment title
- level
- instructions
- writing prompt
- submission area

### Submit Writing Work

Students submit work by pasting their writing into the assignment submission box.

Student steps:

1. Open `Assignments`.
2. Select the assignment.
3. Click or open the homework submission area.
4. Paste the writing answer or essay.
5. Submit the work.
6. Confirm that the assignment shows the submission count updated.

Students currently submit by pasting text into the portal. File upload for student submissions can be added in a later phase if needed.

### View Feedback

Students open `AI Feedback` to see feedback on submitted writing.

Students may see two types of feedback:

- AI feedback generated by a teacher or admin using the AI Tutor
- teacher feedback manually added by a teacher or admin

Students cannot run the AI Tutor themselves. This keeps feedback controlled by the teaching team.

### Shop

Students may open `Shop` to view books, documents, or other paid resources. For now, payment can continue through the existing iLEAP/theileap.com purchase process if Stripe checkout is not fully enabled inside the portal.

### What Students Should Not Do

Students should not be able to:

- see other students' submissions
- change their own level
- edit assignments
- upload official class resources
- change AI Tutor prompts
- create users
- access admin or teacher tools

## 3. Teacher Guide

Teachers use the portal to manage learning activity for assigned levels, review student work, generate AI feedback, and add manual feedback.

### Teacher Login

Teachers should:

1. Go to `https://english.ileapacademy.com/`.
2. Log in with their teacher account.
3. Confirm that they can see only the levels assigned to them.

If a teacher cannot see a level they teach, an admin must assign that level to the teacher.

### Teacher Dashboard

The teacher dashboard should help teachers quickly understand current class activity.

Teachers should be able to see:

- assigned levels
- recent assignments
- student submissions
- resources available to their levels

### Resources

Teachers can use `Resources` to view materials for their assigned levels.

Depending on admin permissions, teachers may also help upload or manage:

- notes
- worksheets
- PDFs
- YouTube links
- class materials

### Assignments

Teachers can view and manage assignments for their assigned levels.

Teachers should be able to:

- create assignments
- edit assignment titles
- edit assignment details or instructions
- publish or unpublish assignments
- assign assignments to the correct writing level

Teachers should not create assignments for levels they are not assigned to.

### Review Student Submissions

Teachers open `Review` to read student submissions.

Teacher steps:

1. Open `Review`.
2. Filter by level or assignment.
3. Select a student submission.
4. Read the student's pasted writing.
5. Review any AI feedback already generated.
6. Add manual teacher feedback if needed.
7. Save the feedback.

After teacher feedback is saved, the student can see it in their `AI Feedback` section.

### AI Tutor

Teachers can use `AI Tutor` to generate feedback for student writing.

Teacher steps:

1. Open `AI Tutor`.
2. Select the student.
3. Select the assignment if applicable.
4. Paste the student's writing.
5. Run AI feedback.
6. Review the generated feedback before relying on it.

The AI Tutor should provide feedback using the iLEAP writing rubric, including:

- mark out of 10
- content
- grammar and punctuation
- academic vocabulary
- structure
- transition words
- overall improvement advice

### Manual Teacher Feedback

Teacher feedback is separate from AI feedback.

Teachers should use manual feedback to:

- correct or clarify AI feedback
- add personal comments
- give encouragement
- explain class-specific expectations
- give next-step writing instructions

### What Teachers Should Not Do

Teachers should not be able to:

- manage payment settings
- manage Stripe settings
- create admin users
- change global portal settings
- edit students outside their assigned levels
- change the main AI Tutor prompt unless admin permission is intentionally given

## 4. Admin Guide

Admins manage the portal setup, users, levels, assignments, resources, AI prompts, and overall operations.

### Admin Login

Admins should log in at `https://english.ileapacademy.com/` using an admin account.

Admins have the highest portal access and should use strong passwords.

### User Management

Admins can manage students and teachers.

Admins should be able to:

- create student accounts
- create teacher accounts
- assign students to levels
- change a student's level
- assign teachers to levels
- disable users
- enable users
- reset temporary passwords

When creating a student, the admin should confirm:

- first name
- last name
- email
- temporary password
- correct writing level

When creating a teacher, the admin should confirm:

- first name
- last name
- email
- temporary password
- assigned levels

### Level Management

Admins control who can access each writing level.

The current levels are:

- Grade 2/3
- Grade 4/5/6
- Grade 7/8/9

Students should only access their own level. Teachers should only access levels assigned to them.

### Resource Management

Admins can upload and manage learning materials.

Resources may include:

- notes
- PDFs
- worksheets
- YouTube links
- downloadable documents
- writing samples
- class materials

Admins should assign each resource to the correct level so students see the right materials.

### Assignment Management

Admins can create and edit assignments for all levels.

Admins should be able to:

- create assignments
- edit assignment titles
- edit assignment descriptions
- assign assignments to levels
- publish assignments
- unpublish assignments
- review student submissions

### Review And Feedback

Admins can open `Review` to see student submissions across all levels.

Admins can:

- view submitted writing
- filter by level
- filter by assignment
- review AI feedback
- add manual teacher/admin feedback
- save feedback for students to view

### AI Tutor Prompt Management

Admins can manage the AI Tutor prompt.

Admins should use `Prompts` to:

- update the AI Tutor instructions
- control the writing rubric
- create prompt versions
- keep feedback aligned with iLEAP Academy teaching standards

Prompt changes should be tested with sample student writing before using them broadly.

### Shop And Products

Admins can manage product listings for books and documents.

Current payment operations may continue through the existing theileap.com process until the portal checkout flow is fully enabled.

Admins should be able to manage:

- product title
- description
- price
- product type
- related level
- purchase availability

### What Admins Should Monitor

Admins should regularly check:

- whether students are assigned to the correct level
- whether teachers have the correct level access
- whether assignments are published correctly
- whether students can submit homework
- whether AI feedback is being generated successfully
- whether teacher feedback is visible to students
- whether uploaded resources open correctly
- whether disabled users cannot log in

## 5. Recommended Portal Workflow

### Weekly Class Workflow

1. Admin or teacher creates an assignment for a level.
2. Student logs in and opens `Assignments`.
3. Student reads the assignment and submits writing.
4. Teacher opens `Review` and reads the submission.
5. Teacher or admin uses `AI Tutor` to generate feedback.
6. Teacher reviews the AI feedback.
7. Teacher adds manual feedback if needed.
8. Student opens `AI Feedback` and reads both AI and teacher feedback.
9. Student improves the writing based on feedback.

### New Student Setup Workflow

1. Admin creates a student account.
2. Admin assigns the correct level.
3. Admin gives the student their login details.
4. Student logs in.
5. Student confirms that resources and assignments are visible.

### New Teacher Setup Workflow

1. Admin creates a teacher account.
2. Admin assigns one or more levels to the teacher.
3. Teacher logs in.
4. Teacher confirms that only assigned levels are visible.
5. Teacher starts reviewing submissions and managing assignments.

## 6. Future Improvements To Consider

The following features are not required for the current phase but would improve the portal later:

- student password change screen
- forgot password email flow
- student file upload for Word/PDF submissions
- teacher comments by paragraph or sentence
- resubmission workflow after feedback
- assignment due dates
- assignment status: not started, submitted, reviewed, revised
- email notification when teacher feedback is ready
- email notification when a student submits homework
- parent account access
- attendance or class schedule
- gradebook or progress reports
- resource search and tagging
- stronger admin audit reports
- production file storage using cloud storage instead of only Render disk

## 7. Simple Role Summary

| Role | Main Purpose | Can Do |
| --- | --- | --- |
| Student | Learn and submit writing | Log in, view level resources, view assignments, submit writing, view AI and teacher feedback, view shop |
| Teacher | Teach and review | View assigned levels, manage assignments, review submissions, run AI Tutor, add teacher feedback |
| Admin | Operate the portal | Manage users, levels, resources, assignments, products, prompts, submissions, and feedback |
