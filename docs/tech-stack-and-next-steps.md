# iLEAP Academy English Writing Portal - Tech Stack And Next Steps

Date: May 20, 2026  
Production URL: `https://english.ileapacademy.com/`  
Primary scope: English Writing Program portal for students, teachers, and admins

## 1. Current Architecture

The portal is built as a full-stack web application.

- Public website and portal UI are built with React.
- Backend API is built with Express.
- Data is managed through Prisma.
- Local and production data use PostgreSQL through Prisma migrations.
- Production deployment on Render uses the `english_portal` schema in PostgreSQL.
- Uploaded files are stored on Render persistent disk for now.
- AI tutor feedback uses the OpenAI API.
- Stripe checkout code exists, but current payment operations may continue through the existing `theileap.com` flow until portal checkout is fully adopted.

## 2. Production Hosting

### Main Website

`ileapacademy.com` remains on SiteGround/WordPress.

### Portal

## 6. Roles And Access

### Admin

Current admin capabilities:

- Login to portal
- Upload resources
- Create assignments
- Create products
- Manage AI tutor prompt versions
- Review student submissions and AI feedback

Needed next:

- Edit existing resources
- Assign resources to levels
- Grant/revoke member access
- Manage student levels
- Manage teacher level assignments
- Manage users directly

### Teacher

Current teacher capabilities:

- Login to portal
- Access assigned level resources
- Create assignments/resources
- Submit writing to AI tutor for feedback
- Review student submissions
- View AI feedback

Needed next:

- Edit student level where permitted
- Access notes and worksheets for assigned levels
- View submissions by assignment and student
- Use teacher-facing AI feedback prompts or teacher notes
- Possibly propose prompt changes, while admin approves final active prompt

### Student

Current student capabilities:

- Login to portal
- See level dashboard
- View accessible resources
- See AI tutor feedback

Needed next:

- See only level-specific notes and worksheets clearly grouped
- Open assignment detail page
- Submit homework directly under an assignment
- See homework submission history
- See teacher-reviewed status
- See AI tutor feedback generated by teacher/admin
- See locked resources only when useful

## 7. AI Tutor

The AI tutor uses OpenAI through the backend only. The API key is stored server-side in environment variables.

Current feedback rubric:

- Mark out of 10
- Content
- Grammar & Punctuation
- Academic Vocabulary
- Structure
- Good Transition Words
- Overall

Prompt versions are stored in the database so old feedback can be traced to the prompt version used.

## 8. File Storage

Current implementation:

- Local dev: `uploads/`
- Render production: persistent disk mounted at `/opt/render/project/src/uploads`
- Database stores `fileKey`
- Files are opened through protected API endpoints

Future production improvement:

- Move file storage to Cloudflare R2, AWS S3, Supabase Storage, or DigitalOcean Spaces.

## 10. Recommended Next Build Phase

The next phase should focus on actual learning operations:

1. Admin resource management
   - edit existing resources
   - delete/archive resources
   - assign resources to levels
   - publish/unpublish resources
   - organize by notes, worksheets, videos, books

2. User and access management
   - admin creates users
   - admin changes student level
   - admin assigns teachers to levels
   - admin grants/revokes resource access

3. Student assignment workflow
   - open assignment detail
   - submit homework under that assignment
   - view previous submissions
   - view AI feedback generated by teacher/admin and teacher review

4. Teacher workflow
   - view assigned levels
   - view notes/resources
   - view submissions by level/assignment
   - review student homework
   - submit student writing to AI tutor
   - optionally add teacher feedback

5. AI tutor prompt permissions
   - admin controls active global prompt
   - teacher can view prompt
   - decide whether teacher can edit prompts directly or submit prompt suggestions

## 11. Open Architecture Questions

- Should students self-register, or should admin create all student accounts?
- Should teachers be able to change student levels, or only admins?
- Should teachers be able to edit the active AI tutor prompt, or should only admins approve prompt changes?
- Should resources be organized by week, unit, level, or content type?
- Should homework submissions allow file upload later, or paste-only forever?
- Should teachers provide manual feedback in addition to AI feedback?
- Should students receive email notifications when homework is reviewed?
- Should admin be able to bulk upload students from CSV?
- Should the portal support parent accounts later?
- Should payments stay on `theileap.com`, or should portal checkout eventually become the main purchase flow?
